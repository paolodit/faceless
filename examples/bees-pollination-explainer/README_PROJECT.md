# Bees and Pollination Acceptance Demo

This input-only Short Explainer is based on a real ChatGPT Work production trial. It is the canonical acceptance case for agent guidance, script-specific art direction, character restraint, supplemental raster coverage, self-contained review boards and portable remote handoff.

The public example includes no generated images, audio, provider keys or private production output.

## Creative Route

- 9:16 comedic science explainer
- premium stylised 2D botanical animation
- recurring Bee Workers, Flower Manager and Wasp Ancestor only when the narration calls for them
- looping final line
- `burst`, `additive`, `steady` and `landing` pacing across the full scene plan

## Acceptance Target

The original trial produced 13 primary frames, but exposed that 13 supplemental raster cutaways were only planned. A truthful run should report each class separately:

- primary scene visuals: present and approved
- supplemental raster cutaways: present and approved
- text and overlay events: code-rendered
- transitions: code-rendered
- narration: present for editor-ready status, otherwise explicitly absent in an assembly draft
- rendered MP4: present or explicitly absent

Use `output/PROGRESS.html` to verify those counts. Use `output/04_images/events/review_board.html` to review supporting cutaways. In a remote workspace, finish with `video-pack export-project --project . --force` and return the generated ZIP.
