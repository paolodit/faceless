# Claude Code Guide

Read and follow `AGENTS.md` before doing any work in this repository. It is the canonical guide for both private content production and Faceless source maintenance.

For a new production, also read `START_WITH_AI.md`. Keep creator work under `productions/`, use the `video-pack` guided commands, and stop at every paid-provider, external-upload and creative-approval gate.

Do not modify Faceless source code merely because the user wants to create a video. Operate the existing CLI unless a genuine tool defect blocks the production.
