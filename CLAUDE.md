# Claude Guide

Read and follow `AGENTS.md` before doing any work in this repository. It is the canonical guide for both private content production and Faceless source maintenance.

For a new production in Claude Code or Claude Co-work, also read `START_WITH_AI.md`. Keep creator work under `productions/`, treat `output/NEXT.html` as the human-facing source of truth, and stop at every paid-provider, external-upload and creative-approval gate.

Guide one decision at a time. Open or link the relevant HTML artifact instead of exposing the command sequence. Refresh the project board after each meaningful action. If the workspace cannot be downloaded directly, create the sanitized portable ZIP with `video-pack export-project --project <path>`.

Do not modify Faceless source code merely because the user wants to create a video. Operate the existing CLI unless a genuine tool defect blocks the production.
