# Profiles

Profiles tune scene pacing, aspect ratio, captions and next-step advice.

List them in the CLI:

```bash
video-pack profiles
```

## tiktok

- Aspect ratio: `9:16`
- Target scene length: 3 seconds
- Caption style: large, mobile-first, highly readable
- Guidance: hook must land within the first 2 seconds.

## youtube-shorts

- Aspect ratio: `9:16`
- Target scene length: 4 seconds
- Caption style: large and clear
- Guidance: prioritize completion and a strong final payoff.

## youtube-long

- Aspect ratio: `16:9`
- Target scene length: 8 seconds
- Caption style: optional or section-based
- Guidance: use chapter-like sections and slower pacing.

## linkedin-video

- Aspect ratio: `4:5`
- Target scene length: 5 seconds
- Caption style: clean, professional and readable
- Guidance: lead with a useful business insight.
